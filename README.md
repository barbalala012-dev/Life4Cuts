# 우리 반 네컷 포토부스

GitHub Pages에서 제공하는 네컷 포토부스 웹앱입니다.

## 기능

- 네 장 촬영 후 100 × 148mm 비율 PNG로 합성
- 전면/후면 카메라 전환
- 프레임을 고른 뒤 사진은 휴대폰 공유 메뉴 또는 파일 다운로드로 저장
- 촬영 사진은 서버에 전송하지 않음
- 프레임 공유는 GitHub 저장소 방식 또는 Supabase 실시간 저장소 방식 중 선택

## 배포

1. 저장소 최상위에 앱 파일과 `frames` 폴더를 올립니다.
2. GitHub 저장소 **Settings → Pages**에서 **GitHub Actions** 배포를 선택합니다.
3. `https://계정이름.github.io/Life4Cuts/` 주소로 접속합니다.
4. 카메라는 HTTPS 사이트에서 권한을 허용해야 사용할 수 있습니다.

## 프레임 크기와 제작

- 투명 PNG 권장 크기: **1181 × 1748px** (100 × 148mm 종횡비, 300dpi 출력용 픽셀 수 기준)
- 캔버스 바깥 여백과 네 장 사진이 보일 영역은 투명하게 둡니다.
- 웹앱에서 사진 네 컷을 합성할 때 프레임 PNG를 위에 겹칩니다.
- Photopea, Photoshop 등에서 새 캔버스를 1181 × 1748px로 만들고, PNG로 내보내면 됩니다.
- 실제 인쇄 대화상자에서 크기를 100 × 148mm로 지정해야 합니다.

## 공용 프레임 추가 방법 A: GitHub에 직접 올리기

이 방법은 교사가 GitHub에 작품을 직접 올리고 배포하는 방식입니다.

1. 학생에게서 완성한 투명 PNG를 받습니다.
2. GitHub에서 `barbalala012-dev/Life4Cuts` 저장소의 `frames` 폴더를 엽니다.
3. **Add file → Upload files**를 눌러 PNG를 올립니다.
4. 변경 내용을 `main` 브랜치에 커밋합니다.
5. `frames/manifest.json`을 열어 다음 항목을 `frames` 배열에 추가하고 커밋합니다. 파일명은 실제 파일명과 똑같이 적습니다.

```json
{
  "name": "별빛 프레임",
  "file": "별빛-프레임.png"
}
```

6. GitHub 저장소의 **Actions** 탭에서 Pages 배포가 완료되면 웹앱을 새로고침합니다. 앱은 manifest 목록과 frames 폴더의 PNG 파일을 함께 읽습니다.\n7. GitHub에 올린 프레임을 삭제하려면 `frames` 폴더에서 PNG 파일을 삭제하고 `frames/manifest.json`에서도 해당 항목을 지운 뒤 커밋합니다.

**중요:** 웹앱의 “투명 PNG 추가” 버튼은 사용자가 방문자의 GitHub 저장소에 파일을 쓰지 않습니다. Supabase 공유 설정 전에는 그 프레임이 올린 기기의 브라우저에만 저장됩니다. GitHub에 직접 커밋하면 해당 저장소를 방문하는 모든 사용자에게 배포 후 공유됩니다.

## 공용 프레임 추가 방법 B: 웹앱에서 실시간 공유

GitHub에 매번 커밋하지 않고 학생이 웹앱에 올린 즉시 반 전체에서 함께 보려면 별도 데이터 저장소가 필요합니다. 이 저장소는 Supabase를 사용합니다.

1. Supabase에서 프로젝트를 생성합니다.
2. Supabase **SQL Editor**에서 저장소의 `supabase-setup.sql` 전체를 실행합니다.
3. Supabase **Project Settings → API**에서 Project URL과 공개용 `anon` 또는 `publishable` 키를 복사합니다. 비밀 `service_role` 키는 사용하지 않습니다.
4. GitHub에서 `supabase-config.js`를 열고 빈 `url`, `anonKey` 값에 위 값을 넣어 `main`에 커밋합니다.
5. Supabase **Authentication → Users**에서 교사 계정을 생성합니다. 해당 사용자 ID를 확인한 다음 SQL Editor에서 다음 명령을 실행해 교사로 등록합니다.

```sql
insert into public.life4cuts_teachers (user_id)
values ('여기에-교사-사용자-ID');
```

6. GitHub **Actions**에서 사이트 재배포 완료를 확인합니다. 이후 웹앱에서 PNG를 추가하면 공용 프레임으로 저장되어 갤러리에 실시간 반영됩니다.
7. 공용 프레임 삭제는 교사 이메일과 비밀번호로 웹앱에 로그인한 뒤 해당 프레임의 **프레임 삭제**를 누릅니다. 개인 프레임은 해당 기기에서 바로 삭제할 수 있습니다.

학생들의 직접 업로드는 공용 저장소에 추가됩니다. 교사 로그인은 삭제 권한에만 필요합니다. 따라서 수업에서는 업로드한 작품을 확인하고, 부적절한 작품은 교사가 삭제해 주세요. 사진 결과물은 어느 방식에서도 서버에 저장되지 않습니다.

## 휴대폰에 사진 저장

1. 촬영을 마치고 **사진 저장 / 공유**를 누릅니다.
2. 지원되는 iPhone에서는 공유 메뉴의 **이미지 저장**을 선택합니다.
3. Android에서는 공유 메뉴의 **다운로드**를 선택하거나 원하는 앱을 고릅니다.
4. 공유 메뉴가 지원되지 않으면 파일 다운로드를 사용합니다. iPhone 브라우저에서 사진이 열리면 이미지를 길게 눌러 사진 앱에 저장할 수 있습니다.
