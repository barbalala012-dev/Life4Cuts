# 우리 반 네컷 포토부스

GitHub Pages에 바로 배포할 수 있는 정적 웹앱입니다.

## 포함 기능

- 카메라로 네 장 촬영, 세로 네컷 이미지 합성, PNG 다운로드
- 공용 프레임 갤러리와 학생이 추가하는 개인 프레임
- 개인 프레임은 현재 브라우저에 저장하고 PNG/백업 파일로 다운로드
- 사진은 브라우저 안에서 처리하며 웹앱 서버로 보내지 않음

## GitHub Pages 배포

1. 이 폴더의 파일과 `frames` 폴더를 GitHub 저장소의 최상위에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 방식으로 **GitHub Actions**를 선택합니다.
3. 게시된 `https://계정이름.github.io/저장소이름/` 주소로 접속합니다.
4. 카메라 권한을 허용합니다. 카메라는 HTTPS 주소에서 작동합니다.

## 반 공용 프레임 추가

1. 학생 작품을 투명 배경 PNG로 받고, 권장 캔버스 크기 `720 × 1440px`로 준비합니다. 사진이 들어갈 네 칸 영역은 투명하게 비웁니다.
2. 파일명을 정리해 `frames` 폴더에 추가합니다. 예: `minji-starry.png`
3. `frames/manifest.json`의 `frames` 배열에 다음 항목을 추가합니다.

```json
{
  "name": "별빛 프레임",
  "file": "minji-starry.png"
}
```

4. 변경 사항을 저장소에 올리면 사이트의 공용 갤러리에 나타납니다.

학생이 웹앱에 직접 추가한 프레임은 해당 기기의 브라우저에만 저장됩니다. 웹앱은 방문자의 GitHub 저장소에 자동으로 파일을 쓸 수 없으므로, 교사가 작품을 검토해 위 절차로 공용 목록에 등록합니다. 사진은 서버에 저장하지 않습니다.
